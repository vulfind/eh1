Practical No. 9

Crack Password Hashes Using John the Ripper
Aim: To crack Linux user password hashes using John the Ripper.
Tools / Requirements: Kali Linux, John the Ripper, /etc/passwd and /etc/shadow (or sample hash file)
Procedure:
  1.   Combine the passwd and shadow files: unshadow /etc/passwd /etc/shadow > combined.txt
  2.   Run John with default wordlist/rules: john combined.txt
  3.   Or specify a wordlist: john --wordlist=/usr/share/wordlists/rockyou.txt combined.txt
  4.   Check the status/progress at any time: john --status
  5.   Show cracked passwords: john --show combined.txt
  6.   Record which accounts were cracked and the recovered passwords.
